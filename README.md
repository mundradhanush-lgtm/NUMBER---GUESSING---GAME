# NUMBER---GUESSING---GAME
THIS IS A NUMBER GUESSING GAME IN WHICH THE USER HAS TO GUESS THE NUMBER BETWEEN 1-1000 THOUGHT BY THE COMPUTER. IT HAS 4 DIFFICULTY LEVELS-- EASY, MEDIUM, HARD AND IMPOSSIBLE AND THIS GAME SAVES THE BEST SCORES FOR ALL THESE FOUR LEVELS SEPARATELY TO MAKE THE GAME MORE INTERESTING. I ALSO USED A LIBRARY NAMED TKINTER FOR THE GUI AND RANDOM FOR THE RANDOM NUMBER. I MADE THIS GAME FOR FUN AND WOULD LIKE YOU TO TRY THIS GAME ONCE.
