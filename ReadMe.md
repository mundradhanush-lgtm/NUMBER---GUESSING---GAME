Ok so this is my improved number guessing game. So, I would first tell you what is the project and what are the features there. So, this game is a Number Guessing Game whaere you have to guess the number between 1-1000 thought by the computer. There are 4 difficulty levels- Easy, Medium, Hard and Impossible. There is also a system of hint, but the catch is that you can only use hint once and that too after a particular number of chances in each level. You need 10 chances to use hint in the Easy level, 8 chances for Medium level, 5 chances for Hard level and 2 chances for Impossible level. This game also saves the best score for each level separarately. So this is all about what is the game and how it is to be played.
